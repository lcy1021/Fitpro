04 / ADOPTION

以后怎么增加新模块

  1. 复用 tokens 和 components，先选已有组件。
  2. 区分页面身份与记录所有者，检查蓝粉和浅深主题。
  3. 保持标题17px、卡内三档字号，选中不加下划线。
  4. 新增语义 token 时补上用途、状态和展示样例。
  5. 验证320/390px、长文字、空态和操作；把原因和修改写入维护记录。
