# DuoFit UI 重构与设计系统工程规范 (AI-Ready Design Spec)

> 本文档专为代码生成与辅助 AI（如 Claude 3.5 Sonnet, Cursor, Copilot 等）编写。它详细定义了 DuoFit 最新版本的色彩令牌、组件布局结构、双端（老公/老婆）差异逻辑以及代码重构指南，AI 可以依据此文档直接进行 HTML/CSS/JS 开发与优化。

---

## 1. 项目概览与双端核心逻辑

- **项目名称**：DuoFit · 两个人的减脂打卡 (Gentler Couple)
- **技术栈架构**：单文件纯静态 Web App (`index.html` + Tailwind CSS / 纯原生 CSS + 原生 Vanilla JS)，无构建打包步骤，支持 PWA / 移动端 Safari 添加至主屏幕。
- **视觉风格**：深度对标 **Gentler Streak** 治愈系风格 —— 温暖奶油底色、双层软糖拟物微光卡片、24-32px 超大圆角、流体渐变能量轨迹（Sweet Spot）、温和零焦虑交互、专属 IP 吉祥物陪伴。
- **双端镜像设计原则**：
  - 老公端与老婆端在 **组件结构、排版间距、层级比例、操作路径** 上完全 **1:1 镜像对齐**。
  - **核心差异** 仅体现在：**身份主题色（蔚蓝 vs 草莓粉）**、**专属吉祥物呈现**、**专属业务数据**（如热量/动作/饮食克数/围度字段）。

## 3. 核心组件结构标准 (Component Architecture)

### 3.1 顶部通用导航 (Header Bar)
- **左侧**：App 标题 `今日 · Gentler Couple` 伴有当前身份指示小绿点。
- **中间偏右**：双身份双向切换胶囊药丸 `[ 老公 ⇄ 老婆 ]`：
  - 选中老公时：老公按钮高亮背景 `#e0f2fe` + 字体色 `#0284c7`。
  - 选中老婆时：老婆按钮高亮背景 `#ffe4e6` + 字体色 `#ff4b72`。
- **右侧**：当前身份的圆形微缩吉祥物头像（老公蓝云 / 老婆粉云），带轻微描边投影。

### 3.2 页面 1：今日主页 (Today Screen)
1. **连续打卡默契条 (Streak Bar)**：
   - 展现 `并肩同频打卡 12 天 · 极佳默契度`。
2. **Gentler 动能状态波浪卡 (Sweet Spot Flow Card)**：
   - 背景：超浅双色微光背景。
   - 标头：`今日状态充沛 / 轻盈！恢复指数 94%~96%`，右上角嵌入对应主角吉祥物。
   - 核心图表：双层平滑渐变 SVG 波浪水流。水流中固定浮动指示点：
     - 老公端：高亮蓝色发光点 `⚡ 我 (老公) · 充沛`，伴随老婆温和点。
     - 老婆端：高亮粉色发光点 `💗 我 (老婆) · 极佳`，伴随老公充能点。
   - 底部提示：贴心无压力的当日运动恢复建议。
3. **双人同频打卡节奏 (Daily 5-Beads Track)**：
   - 两行卡片依次展示老公与老婆。
   - 每个人拥有 5 颗果冻打卡珠：`早 · 午 · 加 · 晚 · 练`（已打卡显示白色对勾，背景填充身份主题色；未打卡呈浅灰色圆点）。
   - 伴侣互动条：如 `老婆刚刚完成了臀腿跟练，送草莓 🍓 / 送打气拳头 👊`，点击即时触发交互动效。
4. **晨昏深曜石训练卡 (Obsidian Workout Card)**：
   - 背景：`#181c24` 深色曜石卡片，极大增强运动聚焦度。
   - 内容：
     - 老公：`哑铃全身循环 A / B`（约 20 分钟），展示 5 个动作胶囊。
     - 老婆：`15 分钟温和臀腿塑形 · 零器械无跳跃`，展示 5 个动作胶囊。
   - **主 CTA 按钮**：高光弥散渐变大按钮 `▶ 开始舒展跟练 (伴随轻松节拍/轻音乐)`，老公端为蔚蓝渐变，老婆端为草莓粉渐变。
5. **温和无压力饮食流水 (Gentle Meals)**：
   - 四张独立白卡：早餐、午餐、加餐、晚餐。
   - 打卡三态选择：`按计划吃啦 ✨` (主色高亮) / `稍吃多 🍰` (温和暖黄) / `还没吃 ⌛` (浅灰态)。
   - 文案规范：点击“稍吃多”时弹出温和无压力提示：“吃多了没关系，下一餐正常吃就好，不要惩罚性节食哦。”
6. **工位喝水 & 舒展计数器 (Water & Stand Counter)**：
   - 包含 `-` 和 `+` 软糖步进按钮，点击数字平滑累加。

### 3.3 页面 2：饮食页面 (Nutrition Screen)
1. **营养微风环 (Gentler Nutrition Ring)**：
   - 左侧为 Circular Progress 环形仪表盘（老公目标 120-130g 蛋白质，老婆目标 80-90g 蛋白质）。
   - 右侧并排当前角色吉祥物插画，附带温和鼓励语。
   - 下方 3 颗胶囊：优质蛋白、复合慢碳、膳食纤维的克数进度条。
2. **一日舒心四餐清单 (Detailed Meals Breakdown)**：
   - 标明推荐就餐时间段、蛋白质估算克数以及菜品建议。
3. **15 分钟快手晚餐轮换 (15-min Dinner Rotation)**：
   - 轮换展示周一至周五省心食谱（如番茄虾仁炒蛋、空气炸锅鸡腿肉等），高亮标记「今晚推荐」。
4. **外卖避坑与选餐指南**：
   - 左栏绿色「舒心优先选」（清蒸、白灼、米饭留半），右栏暖杏色「少焦虑避坑」（少裹粉炸、少浓稠勾芡）。

### 3.4 页面 3：训练页面 (Workout Screen)
1. **双人一周运动步调 (Weekly 7-Day Matrix)**：
   - 7 列并排的日历对比卡片，清晰呈现老公与老婆各自当周的 `练 / 休 / 可选`。
   - 今日列带有圆角高亮光环包裹。
2. **专属跟练动作拆解表 (Workout Details)**：
   - 5 个精选动作流水卡，包含序号、动作名称、要点说明、组数/次数胶囊。
   - 动作支持点击标记完成或进入全屏跟练模式。
3. **伴侣协同动态卡**：
   - 实时显示对方今日是否已打卡、消耗千卡或预计完成时间，支持快速互动发送暖心问候。
4. **工位 3 分钟微拉伸 (Desk Stretches)**：
   - 3 个无需器械的久坐回血小动作（坐姿夹臀、颈部侧拉伸、站姿提踵）。

### 3.5 页面 4：记录页面 (Metrics & Trends Screen)
1. **元气体态洞察卡 (Mascot Insight)**：
   - 顶栏结合吉祥物，强调：“看 3-4 周平滑趋势，肌肉量与水分的自然波动不用焦虑，体脂率在稳步下降就是胜利！”
2. **今日体态录入卡 (Input Form)**：
   - 老公端：晨起体重 (kg) + 核心腰围 (cm)。
   - 老婆端：晨起体重 (kg) + 核心腰围 (cm) + **蜜桃臀围 (cm) + 大腿围度 (cm)**。
   - 多选体态感受胶囊：`力量充沛`、`肌肉泵感`、`轻松轻盈`、`经期温养` 等。
   - 一键主按钮：`☁ 保存并同步到家庭云端`。
3. **双人同频平滑趋势带 (Dual Smooth Trendline)**：
   - 拒绝冷冰冰的传统折线图，采用双色丝滑曲线（蓝线代表老公，粉线代表老婆），标明“持续在舒适温和区间”。
4. **家庭同步口令卡 (Family Sync Token)**：
   - 醒目显示家庭同步口令 `LOVE-FIT-2025-COUPLE`，右侧配备一键「复制邀请码」按钮。

## 4. 给 AI 编码代理的实现准则 (Implementation Rules for AI)

1. **避免单色死板，使用微光与双层背景**：
   - 不要使用粗糙生硬的纯灰色边框，推荐使用 `box-shadow: 0 4px 20px -2px rgba(0, 0, 0, 0.04)` 以及白色主卡片在奶油底色上的色调分离。
2. **严格保持无焦虑文案 (Gentler & Zero Anxiety Copy)**：
   - 严禁出现“失败”、“惩罚”、“严重超标”、“扣分”等冷硬字眼。
   - 所有的打卡状态均以“平稳滋养”、“舒适充能”、“陪伴同行”为基调。
3. **响应式与截断保护 (Anti-Truncation)**：
   - 手机屏幕最大宽度控制在 `440px - 520px` 居中展示。
   - 数字与单位之间使用 `nowrap`，所有多列卡片必须考虑移动端窄屏自适应（如 flex-wrap 或精确 min-width）。
4. **切换动效 (Transitions)**：
   - 点击顶部切换老公/老婆时，通过平滑的 CSS Transition（如 `transition: all 0.3s cubic-bezier(0.4, 0, 0.2, 1)`）平滑改变主题色变量 `--current-primary` 与当前主角吉祥物。
