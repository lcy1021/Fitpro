## v44 四页场景表头

`assets/page-hero/` 存放独立场景资产，不能替换上表中的卡片／登录原版角色。`today-hus-v1.png`、`diet-hus-v1.png`、`train-hus-v1.png` 与 `record-couple-v1.png` 来自用户确认的四页高清规格稿；三张 `*-wife-v1.png` 是以蓝色场景、原版粉色角色和多视角母版共同作为编辑输入生成的对应身份变体。蓝色角色保留卷发、青色帽檐、短圆手臂、深蓝条纹短裤和青色鞋；粉色角色保留高马尾、深粉发带、短圆手臂、条纹运动裙和珊瑚鞋。四页的场景、人物、姿态、道具分别见 [高清规格与实现 QA](../docs/qa/page-header-implementation/README.md)。新变体不覆盖原图，待实机复核时可按页面单独替换素材而不用改变文字／同步逻辑。

手写句使用 `assets/fonts/LongCang-Regular.ttf`，许可在同目录；页面标题、日期、同步状态和手写句是独立 DOM 图层，禁止把真实记录或状态烧入场景图。角色镜头构图按 3:4 比例输出，背景贴边铺满页面安全区，保留原生 iOS 状态栏。

v45 的 `*-v2.jpg` 是上述七张 PNG 的 90% 质量交付编码；像素尺寸、场景构图、角色五官、帽子／发带、手臂、服装、鞋和道具均沿用 v1 源图，不是新角色图。原 PNG 保留用于追溯和后续编辑，正式 App 与组件展示页共用 v2 URL。浅色和深色的渐隐由 CSS 独立控制，不烧入交付图；图片缓存仍是 `duofit-images-v1`，安装新版时预热所有七张场景，减少老婆身份首次切换时的空白风险。

## v53 表头前景层（2026-10-13）

`page-hero/meadow-glass-v1.jpg` 是独立的虚化草地前景，来自图像生成，仅用于今日页横排标题后方，蓝粉共用。无角色、服装、文字或数据；不是新角色资产，不修改七张原版场景。以原今日湖岸草地和已确认磨砂修订稿为参考，输出柔焦绿草／浅色小花纹理，经常规尺寸和 JPEG 编码优化约64KB；CSS羽化并按浅深主题染入页面底色。其他页面不使用这张草地。原始生成文件位于 Codex generated_images，生产文件在 assets 内独立版本命名。
