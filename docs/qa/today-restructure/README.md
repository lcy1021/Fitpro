## 对照与可执行差异

以用户确认的 [390px 蓝浅视觉稿](approved-preview-hus-light-390.png) 和 [390px 粉深视觉稿](approved-preview-wife-dark-390.png) 为目标，同状态修改前为 [v40 蓝浅截图](before-hus-light-390.png)，实现后为 [v41 蓝浅截图](after-today-hus-light-390.png)、[v41 粉深截图](after-today-wife-dark-390.png)。本机预览使用合成数据；v40 截图顶部“未读取配置”橙字是预览环境提示，v41 截图将该提示固定为“已同步 · 刚刚”便于与确认稿比较，两者都不代表真实云端同步结果。

| 项目 | v40 差异 | v41 实现与同屏核对 |
| --- | --- | --- |
| 本周方向/每日状态 | 两张大卡优先占据首屏；状态说明冗长 | 双列紧凑入口，焦点和当日安排生成短词；点击分别进入原周计划与调整今天界面 |
| 伴侣信息 | 今日出现伴侣打卡状态 | 今日移除该模块；记录页的共享详情与权限逻辑保留 |
| 高频顺序 | 训练先于饮食，起身位于末尾 | 概览→原工位起身卡片→今天吃什么→训练；起身内部标题、说明、插图和增减操作不改 |
| 卡片边缘 | 部分模块以角色色细边框区分，内外卡对比弱 | 外层一级中性投影、内卡二级中性投影；饮食/训练/记录与组件页共用 token，功能性输入边框保留 |
| 今日饮食背景 | 外壳较浅，白色餐卡边缘不明显 | 外壳使用 `--ds-meal-scene-bg`，蓝浅约 RGB(238,248,254)、粉浅约 RGB(255,240,241)，白色餐卡清晰独立；深色也按所有者配色分层 |
| 背景/标题小字 | 云层、日期、手写小字来自现有共享组件 | 逐项保留，未将小字并入图片或删除 |
| 角色与餐图 | 原版跑步、起身姿态及餐食图 | 主体、帽子/发型、服装、比例、道具、爱心装饰均沿用原文件和 `mascots.js`；没有重绘或缺失素材 |
