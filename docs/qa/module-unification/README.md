## 逐项视觉清点

- 背景：沿用surface→角色浅色渐变与真实云层图片，深色同步；不是整块蓝/粉底。
- 标题/小字：同层模块沿用19px/800，日期和辅助12px；餐次内部12/14/16px。记录日期仍在标题下。
- 角色主体/姿态/道具：跑步、吃饭和双人来源不变；吃饭保留饭碗/西兰花，新增通用模块复用原有workout/weigh姿态，未生成新脸型/服装。
- 装饰：餐品底托/柔影保留；爱心使用已有sprite并独立轻浮动，尊重减弱动态。数据图表真实按记录生成。
- 内容与交互：只有本人当天可编辑餐食；伴侣/过去只读。原始身体数据/目标仍仅本人读取，没有扩大共享。
