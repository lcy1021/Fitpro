# 首屏场景延伸 · v46 QA

日期：2026-10-13。状态：v46 已发布，原桌面图标真机待验收。

## 依据与可执行差异

用户的深色蓝色「今日」手机截图显示，稍微滚动后湖岸场景已进入灵动岛后方。此前未滚动的粉色「今日」截图顶部为纯白系统栏，场景未绘制。两张截图身份和主题不同，不能据此推出相同原因；但滚动截图足以推翻「该区域永远不能显示网页图像」的断言。本地 v45 同视口模拟 62px 顶部预留：纯色顶条、场景从下方开始。目标是同一张场景在首屏延伸到顶部，且不设置独立的灵动岛背景，标题与首卡在屏幕中的位置保持。

| 核对项 | 修改前 | v46 本机模拟结果 |
| --- | --- | --- |
| 背景顶端 | 预留区为根画布纯色 | 根画布与页头使用当前页同一张场景图；顶端无横向截断 |
| 顶部暗角 | 只作用在页头元素 | 共用 `--ds-hero-top-shade`，浅色透明、深色仅顶部 80px 淡暗角 |
| 标题、日期、同步 | 位于场景下部 | 字体、颜色、文案与首卡物理位置不变；同步仍由真实状态决定 |
| 手写小字、装饰 | Long Cang 与单笔线 | 字体、字句、笔线位置不变 |
| 插图主体、姿态、道具 | 原版蓝/粉角色、湖岸、桥、花草 | 使用原同一张资产，无换图、改姿态或删道具 |
| 首卡与导航 | 原组件 | 未改内容、顺序或状态 |

390px 同视口合成数据对照：[蓝色深色修改前](before-today-hus-dark-390.png) / [修改后](after-today-hus-dark-390.png)；[粉色浅色修改前](before-today-wife-light-390.png) / [修改后](after-today-wife-light-390.png)。这些是 Chromium 加入 62px 模拟状态栏的本机截图，状态文字/图标为占位符，**不是 iPhone 原生状态栏截图**。
