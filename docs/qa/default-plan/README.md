# 确认目标后自动执行计划（2026-10-08）

## 实现方案

- 确认当天为计划第 1 天；预览显示从今天开始的连续 7 天，不再将首日绑定周一。
- 首页显示今天训练或休息、计划第几天、训练时长和默认安排依据。无需填写每日状态即可执行；入口为“调整今天”。
- 连续 7 天为一个训练周期；跨周沿用时保持原起点，每周确认的新安排覆盖后续周期。已有周一计划继续沿用。
- 每日休息或短版仅影响当天，不写入虚假的训练完成记录；身体不适的休息安排继续保留。
- 兼容现有 AI 返回的周一到周日数据，按顺序映射到首周实际日期。确认前跨午夜时重新展示日期，核对后再启用。无需新增 SQL 或部署云函数。

## 验证

- `node tests/default-plan.js`：周四首日、连续 35 天、跨周沿用、身体不适的后续休息、每日覆盖及过期、跨年、AI 日期对齐、保存、午夜复核、旧计划。
- `node tests/scenarios.js`：旧版菜单、私密视图、AI 计划预览、每周确认、同步和身份恢复。
- `node tests/sw-cache.js`：新版联网获取和离线回退。
- 本机手机预览：`http://127.0.0.1:8765/tests/theme-preview.html?view=today&theme=dark`；可设 `person=wife`、`state=rest|short|daily-rest`、`plan-age=4`。
- 脚本与样式地址更新为 `?v=22`；离线缓存 `duofit-v22`。
