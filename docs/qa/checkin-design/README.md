## 两步检查与修改

| 页面 | 修改前的问题 | 本次修改 |
| --- | --- | --- |
| 饮食 | 摘要与密集的周表分离，符号难以说明实际吃了什么 | 摄入范围、餐次进度、七天日期条与餐次日志；今天直接打卡或记食物，历史日期只读 |
| 记录 | 开头缺少坚持反馈，历史打卡没有按日入口 | 双方连续天数、同日连续天数、四周日历；点日期看自己的餐食与活动 |

整体布局检查：320/390px 没有整页横向溢出；蓝粉同时有角色文字，选中日期有描边/底色与 aria-pressed，历史日期的状态有完整文字标签。保留浅色与深色主题。截图中的数值与记录全部是本地合成数据，不是用户真实健康数据。

## 统计与隐私

- 当天存在保存的 check-in 就算记录；无需四餐或训练全部完成。取消某项状态仍保留这一天曾保存打卡的事实。
- 今天尚未打卡时，显示截至昨天的连续天数；昨天断卡则为 0。
- 连续统计窗口为近 120 天，到边界仍连续时显示加号。伴侣范围过旧或旧接口缺少元数据时显示待同步。
- 饮食历史展示当时保存的食物与热量，不使用现在的计划重算过去。
- 伴侣历史仅返回日期与 checked 布尔值；不返回伴侣餐食、目标或原始身体数据。
- 摘要缓存按匿名用户 ID 隔离，保留离线状态查看；过时数据不会被解释为今天已完成。
