# v53 紧凑表头与磨砂前景

## 确认与范围

用户选择三稿中第一张横排方案；随后要求“今日”小一些、信息区高一点、透明／玻璃过渡更强。修订稿 [approved-refinement.png](approved-refinement.png) 展示后用户明确「按这版实现」。图为内置 Image Gen 输出；生产沿用原版角色、场景与字体，生成稿的人物再绘制差异不进入 App。

[同屏对照](compare.html)：相同430px宽、10月13日、已同步10:39、照常训练；左为v52，右为v53真实组件。页面截图无系统状态栏，不能冒充手机原生画面。真实起身计数与按钮是现有功能，概念图漏画的部分在实现中完整保留。

## 修改前的可执行差异

1. 竖排44px标题／日期／同步占据三行，右侧空置；改为左侧36px（320px为32px）标题、右侧两行元信息。
2. 3:4表头下部空白过长；收短到100:112，原图100% auto，人物与道具保持原比例。430px首卡由573.3px上移至481.6px（安装态两者还会减去同一60px）。
3. 场景原图底部已有白雾，单改透明度仍偏白；补独立草地前景，羽化叠在今日文字区。其他场景沿用本身前景的磨砂，不混用草地。
4. 同步空／加载／离线都保留同高右侧行，避免标题与下方组件跳动；实际语义保持，不能为截图把线上同步写死。
