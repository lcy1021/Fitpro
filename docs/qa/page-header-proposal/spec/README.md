## 图层与素材清单

1. **场景底图**：今日湖岸晨光 `today-scene.png`；饮食厨房窗景 `diet-scene.png`；训练晨光运动室 `train-scene.png`；记录傍晚两人围桌 `record-previous-style.png`。四张源图均 1086×1448，独立于文字与数据层。对应文件在 [assets](../assets/) 目录。
2. **角色**：蓝角色深蓝卷发＋青色帽檐、连续云朵身体、短圆手臂、深蓝条纹短裤、青色鞋；记录页粉角色高马尾＋发带、短圆手臂、条纹运动裙、珊瑚鞋。与 [原版身份清单](../../../../assets/mascots.md) 和 [多视角母版](../assets/hus-turnaround.png) 核对后才能用作正式新姿态。场景图已无烧入的页面标题、日期或同步文案。
3. **文字与状态**：页标题、日期、同步状态、手写句均为 DOM 文本；Long Cang 文件与许可证独立保存于 [assets](../assets/)；状态栏仅用于预览，正式使用系统原生状态栏。
4. **首卡**：来自当前 App 运行时。主卡与内卡继续用设计系统的一级／二级中性投影，不把场景当数据卡；保留实际按钮、热量计算和记录逻辑。

## 验证与尚待定稿的状态

- `capture-current.cjs` 和 `capture-spec.cjs` 已在本地 Chromium 对四页做同视口、同合成数据截图。390/320px 共 8 个目标首屏均无横向溢出，Long Cang 加载成功；四页标题／日期／同步行和首卡的 y 坐标逐页一致。截图经人工逐屏检查角色姿态、背景、道具、文字与真实卡片接缝。
- 目前只完成**蓝色身份／浅色／休息日**的高精度首屏稿。粉色身份、深色主题、训练日、加载／离线／错误同步、长文案与 iPhone 实机安全区需要各自素材和同屏验收；不可把此蓝色浅色图直接套给其他状态。若后续接入代码，须再按 AGENTS.md 的 320/390、蓝粉、浅深和交互状态要求完成这些图与 QA。
- 手写线、场景光效和头像动画目前静态。动效按此前约定在页面视觉结构确认后独立制作；`prefers-reduced-motion` 必须可静止。
